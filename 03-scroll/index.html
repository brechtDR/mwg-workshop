The compositor does the work

Scroll-driven animations run off the main thread. The browser maps scroll position to animation progress directly — no events, no throttling, no jank.

scroll()

Ties animation progress to a scroll position: the document, a scroller, any overflow container you name.

view()

Ties progress to an element's own visibility inside its scroller. This is how an element animates itself into view.

animation-range

Decides where in the journey the animation starts and ends. Entry 10% to cover 35% reads like a sentence once you've said it twice.

prefers-reduced-motion

The guard rail. A state change that motion communicates must survive the motion being switched off.
